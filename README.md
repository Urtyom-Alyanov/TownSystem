## TownSystem
_licensed under MIT/Apache-2.0 license_

### Что это?

Данное приложение является комплексной моделью городской системы, состоящей
из моделей разных аспектов жизнедеятельности города. С каждой из этих моделей
вы можете различно взаимодействовать, в том числе и управлять ими. Каждая
модель может влиять и на другую, чаще всего на социальные процессы или экологию.
_Например, постройка завода ухудшает экологию_.

### Реализация

Приложение представляет собой модульное решение, состоящее из `src`, `tests`, `ui`.

- [`/src/`](./src/) - Здесь находится вся бизнес-логика приложения.
- [`/tests/`](./tests/) - Тесты для этой бизнес-логики.
- [`/ui/`](./ui/) - Само приложение и библиотеки для построения интерфейса.

Зачастую каждому проекту из [`src`](./src/) соответствует один проект из [`tests`](./tests/)
и один проект из [`ui`](./ui/).

Такая архитектура специально выбрана, чтобы отделить саму логику от интерфейса, что
позволяет нам реализовывать на базе общей библиотеки и другие интерфейсы,
например web-интерфейс или использовать другой фреймворк. Также это
позволяет прогонять тесты и на другой платформе, отличной от Windows.

Реализация соответствует принципам объектно-ориентированного программирования и
паттерну MVVM (Model-View-ViewModel).

### Где скачать

Скачать последнюю версию вы можете из вкладки `Releases` (она находится сбоку) на Github.
Проект собирается с помощью CI/CD-пайплайна в один большой исполняемый файл, что уже
содержит все библиотеки внутри.

#### Собрать проект

Если вы любитель всё собирать из исходников, ~~то добро пожаловать на [gentoo.org]~~
либо вы просто разработчик или добрый человек, что решил нам помочь в этом нелегком
деле, то процесс сборки проекта из исходного кода не отличается от других .NET проектов.

Если вы прям совсем новый и зелёный, то вот гайд, но [сначала нужны эти программы](#требования-для-сборки):

1. Склонируйте репозиторий `git clone https://github.com/Urtyom-Alyanov/TownSystem`.
2. Перейдите в директорию решения `cd ./TownSystem`.
3. Соберите решение `dotnet run --project ./ui/TownSystem.UIApp/TownSystem.UIApp.csproj`.

Чтобы копировать было легче, то вот полотно команд, которые сразу всё сделают.
```powershell
git clone https://github.com/Urtyom-Alyanov/TownSystem
cd ./TownSystem
dotnet run --project ./ui/TownSystem.UIApp/TownSystem.UIApp.csproj
```

**Также** можно собрать проект в IDE, например в JetBrains Rider или Microsoft Visual Studio,
там нужно просто кнопочки пронажимать (кнопка сборки это зелёная (или акцентного цвета)
кнопочка вперёд). Клонировать репозиторий по этому адресу: `https://github.com/Urtyom-Alyanov/TownSystem`

##### Требования для сборки

- `.NET 10.0` - [скачать можно отсюда](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)
- `git` - [скачать можно отсюда](https://git-scm.com/install)
- `Windows 10/11` - скачайте сами, сами знаете откуда, на иных версиях ОС Windows работа не гарантируется.
